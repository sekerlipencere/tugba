# Tuğba — Kişisel & PDR Blog

Astro 5, Tailwind CSS v4 ve MDX ile hazırlanmış, hem kişisel/edebi hem de Psikolojik Danışmanlık ve Rehberlik (PDR) odaklı kişisel web sitesi.

## Özellikler

- **Yazılar (`/yazilar`)**: Rehberlik, Denemeler ve Kitap ve sinema rafları
- **Duygular sözlüğü (`/duygular`)**: Kısa defter cümleleri ve fotoğraf diptikleri
- **Aklımda kalanlar (`/aklimda-kalanlar`)**: Kitap kulesi ve altı çizili sayfa kupürleri
- **Kitaplık (`/kitaplik`)**: Tür ve hedef kitleye göre filtrelenebilen kitap ve film rafı
- **Rehberlik (`/rehberlik`)**: Mesleki notlar, anonim soru kutusu ve indirilebilir/yazdırılabilir haftalık ders çalışma tablosu (`/rehberlik/calisma-tablosu`)
- **Otomatik OG kartları (`/og/...png`)**: Satori + Resvg ile derleme sırasında üretilen `1200×630` paylaşım görselleri
- **Pages CMS (`.pages.yml`)**: `app.pagescms.org` üzerinden teknik bilgi gerekmeden içerik yönetimi

## Komutlar

```bash
npm install
npm run dev      # Yerel geliştirme sunucusu
npm run check    # TypeScript ve Astro şema kontrolü
npm run build    # Üretim derlemesi (dist/)
npm run preview  # Derlenen siteyi yerel önizleme
```
